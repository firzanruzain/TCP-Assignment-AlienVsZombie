# Alien vs. Zombie

## Compilation Instructions

g++ pf\\*.cpp main.cpp -o main.exe

run main.exe

## User Manual

- When starting the game, a start memu will pop-up where it will ask whether or not the user want to change the game settings or remain it as default. If the user wants to change and customise it to their liking simply press "y" and enter, if the the user wants to reamin as default simply press "n".

- Once the user is done with the game settings, the game board will appear, along with information regarding the Alien and Zombie's health, attack and range(only for the zombie).

-The user is able to control the Alien's movement by entering directions such as, right, left, up, and down.

- On the game board, in the game board the Alien and Zombie are shown as A and 1 respectively, there are also powerups and obstacles that the user can go through. For example, Pods(P), Health(H), Rock(R), Arrows(<,>,^,v).

- The purpose of this game is to gather the powerups to beat the Zombie. That is done by the controlling the Alien to get the powerups such Health and Pods to increase both health and attack.

- Finally, there's an option for the user to save the game by typing "save" in the command which will then lead you to enter a file name.
